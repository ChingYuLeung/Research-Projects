<h2>Undergraduate Research Projects:</h2>

- <b>Final Year Project:</b>
  Correlations between Dynamical Dark Energy and Neutrino Parameters
  [FYP_Preprint](https://arxiv.org/abs/2610.34445)
  - Modified an existing likelihood pipeline in Python to fit a multi-parameter model to multiple observational datasets using Bayesian inference and Markov Chain Monte Carlo (MCMC)
  - Executed MCMC runs in parallel using mpirun and analysed posterior distributions and parameter correlations using GetDist
  - Submitted as first author to The Astrophysical Journal Letters (ApJL)

- <b>University of Tokyo Research Internship Program:</b>
  Energy, Direction and Vertex Reconstruction for a Proposed Water Cherenkov Neutrino Detector at Oak Ridge National Laboratory [UTRIP report](https://www.s.u-tokyo.ac.jp/en/utrip/archive/2024/research-projects/pdf/01.pdf)
  - Builded object-oriented detector simulations in C++ using Geant4 and generated 100,000 Monte Carlo events per simulation
  - Analysed simulated-output distributions of target parameters, calculated means and standard deviations, and visualised results using CERN ROOT


- <b>Summer Undergraduate Research Exchange Program:</b>
  Determining the Arrival Time Delay of Galactic Core-collapse Supernova Neutrino Burst at Different Neutrino Experiments [SURE report](https://github.com/ottoleung1601/Research-Projects/blob/main/SURE_report.pdf)
  - Modified a maximum-likelihood method that estimates time delays between detector signals and edited the corresponding Python modules
  - Evaluated bias, uncertainty and computational runtime against existing methods using 1,000 trials per Monte Carlo simulation; observed lower bias and uncertainty and faster computation under most practical conditions tested


- <b>Summer Undergraduate Research Internship Program:</b>
  Fermionic Dark Matter-Admixed White Dwarf Model [SURIP poster](https://github.com/ottoleung1601/Research-Projects/blob/main/SURIP_poster.pdf)
  - Constructed a dark matter-admixed white dwarf model mathematically
  - Solved coupled physical differential equations in C and made predictions on the properties of these white dwarfs
